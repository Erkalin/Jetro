# Jetro v0.2.0

## Video & Audio
- Download video and audio from YouTube, TikTok, Instagram, Reddit and 1000+ other sites
- Pick video quality or audio format, with subtitles and playlist support
- Cookie file support for login-required videos
- yt-dlp + ffmpeg included, no extra setup needed

## Batch Download
- Add many file parts at once using a `*` pattern
- Preview files before adding and skip failed links

## Interface
- New Details list view with sorting and resizable columns, alongside Card view
- Light / Dark / System theme
- Right-click menu: Open, Rename, Redownload, Refresh, Move to queue, Properties
- File exists, rename, and properties dialogs
- Drag & drop links or .txt files to add downloads
- Update banner when a new version is available

## Queues & Downloads
- Power action when a queue finishes: Sleep, Hibernate, Shutdown or Restart
- Auto-retry for failed downloads
- Per-queue schedules with overnight support

## System
- Minimize to tray with downloads continuing in background
- Startup update check + manual check in Settings
- Simpler Settings with presets for connections and speed limit

## Removed
- VPN detection and kill-switch
- Global scheduler (now per-queue only)
